### 🧾 [LedgerLite](https://github.com/gauravdotio/ledgerlite) — AI receipt & GST expense tracker

An expense tracker built for **small shop owners in India**. Snap a photo of a bill and Gemini reads the vendor, date, total, **CGST / SGST / IGST** and GSTIN. You review it and save. LedgerLite then shows where the money went, warns you before you go over budget, and answers plain questions like *"How much GST did I pay this financial year?"*

| | |
|---|---|
| 📸 **Receipt scanning** | Gemini extracts line items, tax split and a suggested category into Zod-typed JSON |
| 💬 **Ask your ledger** | Natural-language questions answered by read-only AI tools closed over the session `userId` |
| 📊 **Dashboard & budgets** | Month-over-month spend, GST paid, 6-month trend, per-category budgets with pace markers |
| 🔐 **Security** | 3-layer per-user isolation · composite FKs in Postgres · scrypt passwords · magic-byte upload checks |
| ✅ **Quality** | Unit + integration tests against real Postgres (incl. SQL-injection & isolation) · CI on every push |
